A kiemelt képet a hírlista arányára igazítja: átméretezés és kitöltés a kép jellemző színével, előnézettel.

== Description ==

A blokkszerkesztő kiemelt kép panelén megjelenik egy „Igazítás” gomb. Ha a választott kép aránya eltér a beállított cél aránytól, az igazító magától megnyílik. A kép torzítás és vágás nélkül a cél arányú vászonra kerül, a maradék helyet a kép szélének jellemző színe tölti ki. Az eredeti kép megmarad, az igazított új médiaelem lesz.

Beállítás: Beállítások › Kiemelt kép igazítása.
